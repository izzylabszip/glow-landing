# glow-landing

Standalone repository for the Glow marketing landing site (Next.js) — the code that serves https://gloww.dev.

- **Purpose:** day-to-day landing-page work (copy, SEO, blog, sections) by Bishal and the IzzyLabs team, without touching the Glow monorepo.
- **Dev URL:** pushes to `main` deploy automatically to the dev project → https://dev.gloww.dev
- **Production lives in the monorepo:** production (gloww.dev) is deployed from `landing/` in `izzylabszip/Glow`. Changes here do NOT reach production by themselves — production promotion is a separate owner-approved step (manual "Promote to production" workflow, or an explicit instruction to Muse).
- **Who this is for:** Bishal Shah (push access) and Aashish Kant (owner). Muse also works here for the daily SEO autopilot.
